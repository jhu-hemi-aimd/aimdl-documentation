# HELIX

The HELIX instrument: safe operation, experiment setup, diagnostics, and data
capture for laser shock experiments in the AIMD-L Laser Shock Testing Area
(Stieff G30).

!!! warning "Read safety first"
    HELIX uses Class 3B and Class 4 lasers. Read the
    [HELIX laser safety plan](safety/safety.md) before entering the laser
    testing area or operating any part of the instrument.
